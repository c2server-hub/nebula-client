Installation

Prêt en 4 étapes

Moins de cinq minutes entre vous et les étoiles. Aucun launcher exotique, juste Fabric.

Minecraft 1.21.11 version du jeu requise
Fabric Loader ≥ 0.20.1 lanceur de mods léger
Fabric API 0.141.x bibliothèque de base
01

Installez Fabric Loader

Téléchargez et lancez l'installateur Fabric pour Minecraft 1.21.11. Cela crée un profil « Fabric » dans votre launcher Minecraft.

fabricmc.net/use
02

Ajoutez Fabric API

Téléchargez Fabric API (0.141.x + 1.21.11) et placez le fichier .jar dans votre dossier mods.

Modrinth — Fabric API
03

Installez NEBULA

Récupérez nebula-1.0.0.jar depuis la page des releases et copiez-le dans .minecraft/mods, à côté de Fabric API.

GitHub Releases
04

Lancez le jeu

Sélectionnez le profil Fabric, entrez dans un monde et appuyez sur Maj droite pour ouvrir le ClickGUI. Bienvenue dans la nébuleuse.
